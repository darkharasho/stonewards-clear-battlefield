# Changelog

## 0.1.0

- First release. A Clear Battlefield button in the top-right of the pause menu removes weapons dropped by enemies, for the host only.
- Drops are marked as they spawn. Level loot, player drops, non-weapons and stacks merged with a player's drop are never removed.
- Settings for confirmation (on), minimum drop age (0 seconds) and a keybind (none).
